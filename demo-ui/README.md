# Streamlit Demo UI

M3 추가: compose.m3-app.yaml 적용 시 로컬 운영자용 직접 작성 초안·승인/거절·최근 실행·재개 화면을 표시합니다. 토큰은 Streamlit 서버 환경에만 둡니다. 이 화면은 단일 사용자 로컬 시연용이며 브라우저 사용자별 로그인 구현은 아닙니다. `test_tickets_ui.py` 2개 AppTest 통과. 실제 컨테이너와 브라우저 검증은 대기입니다.

M1에서 날짜·등급·분류·상태·페이지를 선택해 장애 표를 조회합니다. API에서 받은 결과만 표시하며 연결 실패와 빈 결과를 구분합니다.

UI 서버는 조회자 토큰을 환경 변수에서 사용합니다. 브라우저에 비밀을 렌더링하지 않습니다. 로컬 단일 사용자 시연용이며 로그인·운영자 전환·채팅·승인은 아직 없습니다.

실행은 [통합 안내](../docs/runbook.md)를 참고하세요. 화면 상호작용 검사는 루트에서 `uv run pytest demo-ui/tests -q`로 실행합니다.

M2 적재·기동·seed 후 `uv run --no-sync python scripts/smoke_m2_ui.py`로 실제 API를 호출하는 화면 요소 검사를 실행합니다. HTTP 응답을 대체하지 않으며 장애 표, 검색 원문·거리·출처, 원문 모드 표시와 보류 시 이전 근거 제거를 확인합니다. AppTest는 브라우저 픽셀/레이아웃 검증이 아니므로 실제 브라우저 확인은 별도입니다. 같은 명령을 수동 M2 통합 workflow에 등록했습니다. 원격 실행 결과는 아직 없습니다.
