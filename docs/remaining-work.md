# 남은 작업과 재개 지점

현재 M0 설계·M1 업무 조회 검증 완료. M2는 실제 BGE-M3/Chroma 검색 → LangGraph → OpenAI 생성 답변 → Streamlit 출처 표시까지 연결했습니다. 사용자 화면에서도 생성 답변을 확인했습니다. M2 전체 완료는 아닙니다.
