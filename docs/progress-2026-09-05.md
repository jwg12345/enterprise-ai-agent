## GitHub에 오늘 저장하고 내일 이어가기

프로젝트 자체 .git이 없고 Git이 상위 드라이브 루트를 저장소로 인식했습니다. 현재 상태에서 git add .를 실행하지 않습니다. 상위 저장소를 삭제하거나 수정하지 않습니다.

1. 프로젝트 폴더에 독립 Git 저장소를 초기화합니다: `git init -b main`.
2. `git rev-parse --show-toplevel` 결과가 이 프로젝트 폴더인지 확인합니다.
3. .gitignore와 등록할 파일을 검토합니다. .env, 키, .venv, work, 모델 캐시, DB 데이터, 빌드 결과는 제외하고 소스·문서·테스트·lock·.env.example을 포함합니다.
4. git add . 후 git diff --cached --stat 및 실제 등록 내용을 검토하고 첫 커밋을 만듭니다. 완성되지 않은 M2도 진행 중임을 명시하여 저장할 수 있습니다.
5. 사용자 GitHub 계정에 빈 저장소를 만듭니다. 이름과 공개/비공개를 결정하고 정확한 저장소 URL을 확인한 후 origin 연결 및 push를 수행합니다.
6. GitHub 파일과 Actions 결과를 확인합니다. 이 문서를 쓴 시점에는 초기화·커밋·원격 업로드를 수행하지 않았습니다.
7. 내일 같은 PC에서는 기존 폴더에서 변경 상태를 먼저 확인하고 이어갑니다. 다른 PC에서는 clone 후 환경 파일·모델·DB를 별도로 준비합니다. GitHub는 로컬 컨테이너/모델/비밀을 백업하지 않습니다.

재개 요청 예시: “AGENTS.md, docs/m2-status.md, docs/progress-2026-09-05.md, docs/troubleshooting.md를 읽고 M2 중단 지점부터 이어가줘. 완료된 설치와 이미지부터 확인하고, 실제 검증 결과와 개선 과정을 기록해줘.”
